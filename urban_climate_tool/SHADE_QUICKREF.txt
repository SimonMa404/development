## Terminal Tips

| Need | Command |
|------|---------|
| Activate environment | `source .venv/bin/activate` |
| Build DSM | `python scripts/generate_dsm_only.py` |
| Full shade run | `python scripts/generate_shade_rasters_phase2.py --date 2023-07-21 --register` |
| Quick test | `python scripts/test_shade_quick.py` |
| Restart backend | `docker compose restart backend` |
| Stop running | `Ctrl+C` |

---

## Common Issues

| Problem | Fix |
|---------|-----|
| "Command not found" | Make sure you're in the project folder and venv activated |
| No progress visible | Process is running, just slow at start. Be patient! |
| Process seems stuck | Check if CPU is busy (normal for rasterization) |
| Want different date | `python scripts/generate_shade_rasters_phase2.py --date 2023-06-21 --register` |
| Want fewer timestamps | `python scripts/generate_shade_rasters_phase2.py --date 2023-07-21 --times 08:00,12:00,18:00 --register` |
